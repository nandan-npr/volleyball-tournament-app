# VolleyLive — Volleyball Tournament App

A mobile-friendly React + Firebase app for a four-team **League + Knockout** volleyball tournament.

## Features

- No spectator login or signup.
- Organizer creates a tournament with organizer name, mobile number, location and date.
- Unique public Tournament ID.
- Separate private organizer key generated by the backend.
- Four teams, minimum six players plus substitutes.
- Six round-robin league fixtures.
- Best-of-three manual set score entry.
- Real-time spectator updates with Firestore listeners.
- League points table, semi-finals, final and champion banner.
- Shareable tournament URL: `https://YOUR_HOST/?id=TOURNAMENTID`.

## Scoring model

- Best of three sets.
- First and second sets: 25 points, win by 2.
- Deciding set: 15 points, win by 2.
- League points: 3 points for a 2–0 win; 2 points for a 2–1 win; losing team receives 1 point in a 1–2 loss.
- Current table tie-break: set-point differential.

**Important:** Starter functions validate set winners and best-of-three structure, but do not yet enforce exact 25/15 point targets or win-by-two. Add server-side rule enforcement and test it before an official tournament.

## Firebase setup

1. Create a Firebase project at https://console.firebase.google.com.
2. Register a Web App and copy its Firebase configuration.
3. Enable Cloud Firestore.
4. Install Firebase CLI: `npm install -g firebase-tools`.
5. Sign in: `firebase login`.
6. Copy `.firebaserc.example` to `.firebaserc` and replace the project ID.
7. Create `.env` in the project root with:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_APP_ID=your_app_id
```

8. Install frontend dependencies: `npm install`.
9. Install Functions dependencies: `cd functions && npm install && cd ..`.
10. Deploy rules and Functions: `firebase deploy --only firestore:rules,functions`.
11. Build and deploy hosting: `npm run build && firebase deploy --only hosting`.

Cloud Functions deployment may require the Firebase **Blaze** billing plan. Configure a budget alert first. Free quotas are limited and not unlimited.

## Local development

```bash
npm install
npm run dev
```

The app requires a configured Firebase project and deployed callable Functions.

## Organizer key

The organizer key is generated by the backend; only its SHA-256 hash is stored in Firestore. The key is stored in the creator's browser localStorage. Clearing browser data or changing devices loses access. Keep the creator device secure and do not share the key.

Add a secure organizer-key recovery/transfer flow before production use.

## Production hardening checklist

- Enforce 25/15 set target and win-by-two on the server.
- Add match schedule, court/venue and start time.
- Add tests for score validation, standings and knockout progression.
- Add organizer-key recovery/transfer.
- Add App Check, rate limiting and abuse protection.
- Consider QR sharing and printable fixtures.
